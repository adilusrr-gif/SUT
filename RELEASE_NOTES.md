# Süt 2.1.0 — 23.09.2026

Основа: сохранённый SUT_Ration_v2_Release.zip от 12.09.2026. Обновлён этот архив, версия содержимого — 2.1.0.

## Реализовано

OpenAI Responses + JSON Schema, переключение OpenAI/Ollama/disabled, общий пилотный код доступа, безопасная подстановка чисел в пояснение, PostgreSQL-кэш, атомарный дневной лимит попыток, отображение источника пояснения/кэша/счётчика в UI, безопасные сообщения при сбоях. OpenAI-ключ остаётся на сервере. Внешний запрос передаёт три агрегированных признака без названий фермы, кормов и денежных сумм.

Compose по умолчанию не запускает GPU/Ollama, приложение публикуется на loopback. Добавлены генератор секретов и инструкции обновления без смены PostgreSQL-пароля/тома. Bootstrap больше не скачивает модель автоматически. Добавлен package-lock для воспроизводимой установки frontend.

## Подтверждённые проверки

- 17 тестов прошли (SQLite): исходный тест оптимизатора и 16 сценариев интеграции/защиты/сбоев/квоты.
- Подтверждены контракт OpenAI Responses, валидация схемы, отсутствие новых вызовов при попадании в кэш, отказ без авторизации, обработка 401/429/500/таймаута/отказа/неполного/неправильного ответа.
- Параллельный тест: 12 попыток резервирования через 8 потоков и независимые DB-сессии при лимите 3 — ровно 3 разрешены.
- Расчёт оптимизатора не меняется после запроса объяснения; при сбоях модели расчёты продолжаются.
- TypeScript + Vite: сборка frontend успешна.
- Запросы OpenAI и Ollama в тестах перехвачены MockTransport. Реального платного inference не было.

## Непроверенное

Docker CLI отсутствует: образ не собран, Compose/PostgreSQL не запущены. Тесты SQLite не доказывают поведение PostgreSQL в пользовательском окружении. Реальный OpenAI-ключ, доступ к модели, развёртывание, TLS, браузерные клики и Sites не проверены/не подключены.

Сохранились предупреждения устаревших API FastAPI startup и datetime.utcnow. Они не вызвали падения тестов. Полный security-аудит, сканирование зависимостей и production-оценка в этот проход не выполнялись.

Ветка v2 отличается от предыдущего stateless-сервиса: это отдельная самостоятельная установка. Общий пилотный токен не заменяет персональные аккаунты, роли и изоляцию хозяйств. Неизменяемые снимки исходных данных, запрет применения устаревших рекомендаций, фактические кормовые расходы и достоверная финансовая история остаются следующим этапом.
