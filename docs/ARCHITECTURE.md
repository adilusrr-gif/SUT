# Архитектура 2.1

Браузер → Nginx → FastAPI → PostgreSQL. FastAPI выполняет SciPy-расчёт независимо от LLM. Бизнес-маршруты защищены общим пилотным Bearer-кодом; /api/health публичен. OpenAI-ключ не передаётся браузеру.

Пояснение: загрузка сохранённого OptimizationRun → сбор локального payload → поиск кэша → атомарное резервирование дневной попытки → OpenAI Responses или Ollama → валидация enum → шаблон с исходными числами → сохранение кэша. При отказе/ошибке/лимите — шаблон без модели.

OpenAI получает только changes_count, savings_positive, has_warnings. Ответ модели не может содержать новые суммы/рационы: схема запрещает дополнительные поля. Названия кормов и цифры вставляются локально, текст в React отображается как обычный текст.

AIExplanation хранит кэш, AIDailyUsage — попытки по UTC-дате. Новые таблицы создаются унаследованным create_all. Один экземпляр рассчитан на одну пилотную ферму. UI не даёт менять серверные ключи и лимиты. Для production нужны роли, миграции, аудит, восстановление резервных копий и история исходных данных.
